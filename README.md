# 🍲 FastMCP 기반 식품영양정보 조회 서버
이 프로젝트는 식품의약품안전처의 식품영양성분DB를 활용하여 식품 정보를 검색하는 **FastMCP(Model Context Protocol)** 서버입니다. 이 서버는 특정 식품의 영양 성분을 조회하는 기능을 제공하며, 챗봇이나 다른 AI 애플리케이션에 연동하여 사용할 수 있습니다.

---

## 주요 기능

* **식품 영양 정보 검색**: 식품명, 업체명, 식품대분류명 등 다양한 조건으로 식품의 영양 정보를 검색할 수 있습니다.
* **API 연동**: 공공데이터 포털의 식품영양성분DB API를 호출하여 최신 데이터를 가져옵니다.
* **한글 키 변환**: API 응답의 영문 키(`FOOD_NM_KR`, `AMT_NUM1` 등)를 한글 키(`식품명`, `에너지(kcal)`)로 자동 변환하여 사용자 친화적인 데이터를 제공합니다.

---

## 사용 방법

### 1. `.env` 파일 설정
공공데이터 포털에서 발급받은 **API 서비스 키**를 환경 변수로 설정해야 합니다. 프로젝트 루트 디렉터리에 `.env` 파일을 만들고 아래와 같이 키를 입력하세요.

```Ini
API_KEY=YOUR_API_KEY
```

---

## 툴 사용 예시
`getSearchFood` 툴은 식품명(`FOOD_NM_KR`), 업체명(`MAKER_NM`), 식품대분류명(`FOOD_CAT1_NM`) 등을 인자로 받아 식품 정보를 검색합니다.

### 예시 1: '김밥' 검색

```python
getSearchFood(FOOD_NM_KR="김밥", pageNo=1, numOfRows=5)
```

### 예시 2: 'CJ제일제당'의 '즉석밥' 검색

```python
getSearchFood(MAKER_NM="CJ제일제당", FOOD_CAT1_NM="즉석밥", numOfRows=3)
```

```json
[
  {
    "번호": "5",
    "식품코드": "D101-007000000-0001",
    "식품명": "김밥",
    "에너지(kcal)": "140.000",
    "단백질(g)": "4.84",
    "지방(g)": "4.55",
    "나트륨(mg)": "307.000",
    "식염상당량(g)": "0.78",
    ... (더 많은 영양 성분)
  }
]
```
